# Reports

---

## What this actually is

Not a separate page — a report generator you reach from a **Generate Session Report** button on the session and analytics pages. Point it at a session, pick what kind of report you want and who it's for, and it builds a document you can print, save as PDF, or export as JSON for further analysis.

![Report options modal](/docs/report-options.png)

---

## Four report types, three audiences

The **type** decides what the report is actually about:

| Type | Answers |
|---|---|
| Session Report | What happened in this specific session? |
| Progress Report | How is the rider progressing over time? |
| Diagnostic | Can we actually trust this data? |
| Rider / Parent | Plain-language summary, no jargon |

The **audience** setting decides how much detail and technical language goes into it — **Simple** (rider or parent, plain language throughout), **Standard** (club-level rider, some technical context assumed), or **Coach** (full detail, nothing simplified). Same underlying data either way; this just controls how much gets shown and how it's explained.

Every report includes an executive summary with a confidence indicator, session quality metrics and repeatability analysis, a technique breakdown with scores and recommendations, the visual charts and performance curves, and a data quality assessment — so even the simplest version tells you plainly whether the numbers in it can be trusted, rather than presenting everything with false uniform confidence.

---

## Why you'd actually use this

The obvious use is handing something to a coach who doesn't have (or want) direct access to the analytics platform — a self-contained document instead of a login. It's also useful for keeping an external record independent of the app, or for the JSON export specifically if you or someone else wants to run your own analysis outside the platform.
