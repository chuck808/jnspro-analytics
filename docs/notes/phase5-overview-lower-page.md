# Phase 5 overview lower-page intent

The Overview layer should not repeat the same session metrics or run-progression charts after `SessionHero` has already established them.

Lower-page order should answer:

1. what the session means (narrative),
2. what changed relative to goals/setup/context,
3. the primary strength and primary focus area,
4. whether any runs were excluded from normal statistics,
5. where to continue for dense run-level analysis.

`CrossRunProgression` and the six-card duplicate session-stat grid belong outside Overview; their deeper comparisons remain appropriate for Analysis/Deep Dive.
